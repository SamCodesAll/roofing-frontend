# Image Refactor Notes

## Why illustrations instead of real stock photos

Every image in this project was originally sourced from Unsplash. This refactor
removes **all** external image dependencies — but real stock photography
(Unsplash, Pexels, Pixabay, etc.) could not be downloaded during this refactor
because the build environment's network access is restricted to a fixed
allowlist (npm/PyPI registries, GitHub, Ubuntu package mirrors) and does not
include any image CDN. This was tested directly against Unsplash, Pexels, and
Pixabay — all returned `403 host_not_allowed`.

**What was done instead:** every remote image was replaced with an original,
procedurally-generated SVG illustration, built in the site's actual brand
colors (`src/index.css` `@theme` tokens). These are 100% local, license-free
(generated by code in this repo, not downloaded from anywhere), and satisfy
every technical requirement: zero external URLs, zero broken images, builds
and runs cleanly.

**This is a placeholder layer, not a final asset layer.** Swap in real
photography whenever you have it — see below.

## How to swap in real photos later

Every image is imported by file path, e.g.:

```js
import heroImage from '@assets/images/hero/hero-roofing-crew.webp';
```

To replace one:
1. Add your real photo to the same folder (e.g. `src/assets/images/hero/hero-roofing-crew.jpg`)
2. Update the one import line's file extension to match (`.svg` -> `.jpg`/`.webp`)
3. Nothing else changes — no component code needs editing

This mirrors the original spec's "Future-Proofing" intent: swapping assets
shouldn't require touching React components.

## Known limitation: Open Graph image

`constants/seo.js` -> `DEFAULT_OG_IMAGE` now points to a local SVG (resolved to
an absolute URL at your deployed domain). **SVG has inconsistent support as a
social-preview image** — LinkedIn and some Facebook/Slack link-unfurl bots
don't render it. Before real launch, replace this with a proper 1200x630
JPG/PNG.

## Regenerating or editing the illustrations

The generator that created these SVGs lives at
`scripts/generate-placeholder-images.py`. Run it from the project root:

```bash
python3 scripts/generate-placeholder-images.py
```

It's plain Python (stdlib only, no dependencies) that writes SVG XML directly
— edit the color constants or scene functions at the top of the file to
adjust the illustration style.

## Scope note

This refactor covers **images** only, per the original spec's scope. Two
other external references remain, deliberately:
- **Google Fonts** (`fonts.googleapis.com`/`fonts.gstatic.com` in `index.html`) — typography, not imagery
- **Google Maps embed** (`components/serviceAreas/MapEmbed.jsx`) — a required interactive map feature (iframe), not a static image

If you want those removed too (self-hosted fonts, static map image instead of
an embed), that's a separate, explicit request.
